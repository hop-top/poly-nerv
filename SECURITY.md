# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub security advisories:
[open a draft advisory](https://github.com/hop-top/poly-nerv/security/advisories/new).
Do not open a public issue for a security report.

Include the affected component (CLI, daemon, adapter, or SDK), the
version or commit, and steps to reproduce.

## Supported versions

nerv is pre-1.0. Fixes land on `main` and ship in the next release;
older releases are not patched.
